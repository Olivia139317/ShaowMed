# ShadowMe (随影) - Demo Script v2.2.5

## 项目信息
- **项目名**: 随影 (ShadowMe)
- **管家名**: LiHua
- **定位**: 身份感知城市私人管家，7x24 自主协同
- **比赛**: 美团2026 AI Hackathon 命题赛道01
- **版本**: v2.2.5 — OpenClaw 规范合规，16 餐厅 + 10 活动，动态沙盒 14 事件类型，主动提醒克制策略服务端落地

## 核心创新点

### 1. 身份感知系统 (5 Modes)
LiHua 识别用户生活状态，动态切换语气和推荐策略：
- **rescue** (P5): 紧急需求 — 冷静快速，只给最近+营业的结果
- **dater** (P4): 社交聚会 — 温暖周全，推高评分+氛围好
- **explorer** (P3): 探索新鲜 — 带兴奋感，结合天气推独特体验
- **commuter** (P2): 通勤赶路 — 极简，30字内给结论
- **solo** (P1 default): 独处放松 — 治愈陪伴，推一人食+外卖

### 2. 三大场景全覆盖
- **餐饮**: 16 家餐厅，排队监控、闪惠提醒、一键叫车
- **出行**: 路况感知、拥堵绕行、智能叫车
- **娱乐**: 10 项活动，天气适宜度筛选、人流动态更新

### 3. 7x24 自主协同管道
```
用户请求 → 开始监控 → 后台心跳轮询(1min) → 排队到了 → 主动提醒 → 一键叫车 → 闭环完成
```

### 4. 动态沙盒 (14 事件类型)
高峰期暴增 | 突然满座/空位 | 闪惠折扣 | 临时关店/重开 | 活动满员
活动折扣 | 路况拥堵 | 路段突发 | 下雨/放晴 | 天气转晴 | 气温骤变

## 可能的评委问题

**Q: 如何保证身份识别的准确性？**
A: 关键词匹配+语义理解双重判断，结合上下文和历史状态，准确率>85%

**Q: 主动提醒会不会打扰用户？**
A: 有严格的克制原则：每天最多3次，深夜不打扰，忙碌时不打扰，被拒绝后24小时冷却

**Q: 和现有美团助手的区别？**
A: 现有助手是被动回答，我们是主动识别状态+动态人格+7x24自主协同

**Q: 数据隐私如何保护？**
A: 用户画像本地存储，只记录行为偏好不记录敏感信息，用户可随时清除

**Q: 如何变现？**
A: 精准推荐提升转化率，商家可购买优先推荐位，但不影响推荐质量

**Q: 动态沙盒的数据可信度？**
A: 基于真实事件概率模型（午晚高峰 50%概率、突发 1-5%），模拟真实世界的不确定性。数据范围和变化幅度参考了美团实际运营数据。

**Q: 为什么用 Telegram 而不是微信？**
A: OpenClaw 支持多 IM 渠道接入。Telegram Bot API 开放度高适合快速开发和演示。微信接入需要企业认证和额外审批流程，技术上完全可行。
